# Instalador SuitePSO — releases

Ejecutable del instalador del complemento SuitePSO de Excel para Grupo Puentes. Cada release lleva `Instalador_SuitePSO.exe`; el instalador instalado en los equipos se actualiza solo desde la última release.

El programa solo funciona en equipos de Grupo Puentes (cuenta de Office 365 de grupopuentes.com o dominio PUENTES) y no contiene credenciales. Código fuente: repo privado `valoria-governance/instalador-suitepso`.
